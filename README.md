# 변형 버피 1분 체력 테스트

카메라로 60초 동안 변형 버피 횟수를 자동으로 세는 웹앱입니다. 영상은 폰 안에서만 처리되고 저장·전송되지 않으며, 기록(횟수)만 브라우저에 저장됩니다.

- 앱: `index.html` (단일 파일, GitHub Pages로 게시)
- 판정 엔진: `src/engine.js` (카메라와 무관한 순수 함수)
- 엔진 테스트: `node src/test_engine.js`

## 사용 방법
1. 폰(사파리)으로 게시 주소를 엽니다. 카메라는 HTTPS 주소에서만 켜집니다.
2. 폰을 **가로**로 세우고 **옆모습**이 보이게, 머리부터 발끝까지 보이도록 2~3m 떨어집니다.
3. 전신이 인식되면 시작하고, 60초 동안 변형 버피를 합니다.
4. 횟수가 다르면 결과 화면에서 ±로 고치세요. 판정이 어긋나면 **진단** 버튼으로 무릎·기울기 각도를 보면서 기준값을 조정할 수 있습니다.

## 변형 버피 1회
서기 → 쪼그려 앉아 손을 바닥에 → 발을 뒤로 보내 플랭크 → 앞으로 스텝 후 일어서기. 푸시업과 점프는 하지 않습니다. 네 단계를 순서대로 거쳐야 1회로 셉니다.

체력 측정용이며 진단 목적이 아닙니다.
